# reader-sdk — قارئ البطاقة الذكية البحرينية (Bahrain Smart Card Reader)

> Spec §3.6 — Identity Reader Adapter layer. هذا المجلد يحتوي نسخة معتمدة محلية من
> SDK القارئ وبرنامج التشغيل، مع طبقة تجريد كاملة داخل النظام بحيث لا يعتمد أي
> كود على تفاصيل الـ SDK مباشرة.

## المحتويات / Contents

| الملف | المصدر | الدور |
|---|---|---|
| `bin/SCardReadServer.7z` | `https://s3-eu-west-1.amazonaws.com/smartcard-update/erevealer/downloads/SCardReadServer.7z` | خادم قراءة البطاقة الذكية (SDK) |
| `bin/eRevealerSetup.7z` | `https://smartcard-update.s3-eu-west-1.amazonaws.com/erevealer/downloads/eRevealerSetup.7z` | برنامج القارئ eRevealer |
| `bin/SHA256SUMS.txt` | محسوبة محلياً | بصمات SHA-256 للتحقق من السلامة |

الملفات الثنائية مستثناة من git (`.gitignore: /reader-sdk/bin/`) — تُدار كأصول
داخلية موثقة بالإصدارات ولا تُنشر في المستودع البرمجي.

## احتياطات ما قبل الاعتماد (إلزامية — منظمّة كإجراءات موثقة)

1. **التحقق من المصدر:** نُزّل الملفان مباشرة من روابط الجهة المصدرة أعلاه
   (S3 bucket الرسمي لتحديثات القارئ). تحقق من البصمات في `bin/SHA256SUMS.txt`
   قبل أي فك ضغط، واطلب من المورّد Checksum موقّعاً وشهادة نشر عند التوفر. `[تحقق]`
2. **الفحص المعزول:** افحص ملفات `.7z` داخل VM معزولة بمضادات فيروسات متعددة
   المحركات، وراجع التوقيع الرقمي للتنفيذيات واتصالاتها الشبكية قبل التثبيت. `[تحقق]`
3. **حق الاستخدام:** أكّد حق الاستخدام التجاري للـ SDK وموافقة الجهة المصدِرة
   للبطاقات على القراءة داخل نظام خاص قبل الإنتاج. `[تحقق]`
4. **نسخة داخلية:** هذه النسخة المحلية هي المرجع — لا تعتمد على الروابط
   الخارجية وقت التركيب.

## المعمارية — وكيل القارئ (Reader Agent)

```
[بطاقة ذكية] ⇄ [SCardReadServer (Windows)] ⇄ Reader Agent محلي ⇄ REST/WS ⇄
   src/server/devices.ts (Identity Reader Adapter) ⇄ التسجيل/الاستقبال/الأكشاك
```

- **طبقة التجريد:** `src/server/devices.ts` يعرّف واجهة موحّدة (فتح ملف بالهوية
  المقروءة، حالة القارئ، قائمة الأجهزة) ولا يستورد أي شيء من الـ SDK مباشرة.
- **الوكيل المحلي:** عملية صغيرة على جهاز الاستقبال تتحدث مع SCardReadServer
  وتنشر قراءات الهوية (CPR، الاسم، تاريخ الميلاد، الجنس، تاريخ الانتهاء)
  عبر `POST /api/kiosk/reader-scan` بعد التحقق منها.
- **الاستبدالية:** يمكن استبدال الـ SDK أو الوكيل دون أي تغيير في بقية النظام
  لأن كل الاستهلاك يمر عبر العقد المعرّف في `devices.ts`.

## التثبيت (أجهزة الاستقبال/الأكشاك — Windows)

1. ثبّت مشغّل القارئ ثم شغّل `eRevealerSetup.7z` (فك الضغط والتثبيت كمسؤول).
2. شغّل `SCardReadServer` وتأكد من ظهور القارء في إدارة الأجهزة.
3. عيّن عنوان الوكيل المحلي في إعدادات جهاز الاستقبال داخل النظام
   (الإعدادات ← الأجهزة ← قارئ الهوية).

## ملاحظة أمنية

- الملفات تنفيذيات Windows — لا تُشغّل خارج بيئة معزولة وموثوقة.
- أي تحديث مستقبلي للـ SDK يجب أن يمر بنفس الاحتياطات الأربعة أعلاه ويُحدَّث
  `SHA256SUMS.txt` مع كل إصدار.
