# GNU Health — المرجع الوحيد خارج GitHub

> Spec §2.1 #5 — GNU Health (منظومة HMIS كاملة من مؤسسة البرمجيات الحرة).

## لماذا لا يمكن استنساخه محلياً

يطوَّر GNU Health على مستودع Mercurial في **GNU Savannah** (`hg.gnu.org/gnuhealth`)
وليس له مستودع GitHub رسمي (المستودعات التي تحمل الاسم على GitHub مرايا غير رسمية
غير مضمونة الحداثة). لذلك اعتمدنا التوثيق الوظيفي بدلاً من الاستنساخ المباشر،
مع تغطية قدراته داخل BMC كما يلي.

## القدرات المطلوبة من GNU Health ومقابلها في BMC

| قدرة GNU Health | مقابلها في BMC | الحالة |
|---|---|---|
| وحدة الطب النفسي (psychosocial) | قسم الاختصاص النفسي + قيود الخصوصية العليا (عرض مقنّع + break-glass) | مغطى |
| وحدة الأطفال وحديثي الولادة | قسم طب الأطفال + منحنيات النمو WHO بالمئينات (§17.12) + التطعيمات | مغطى |
| الفحص الوقائي (Preventive/Prenatal) | فحوص الحمل ضمن الكتالوج + تطعيمات + نمو | مغطى جزئياً |
| الصحة المهنية للعاملين | سيناريو «موظف يعالَج كمريض» + سجل موظف-مريض منفصل | مغطى |
| التغذية العلاجية | قسم التغذية العلاجية + خطة تغذية ضمن الـ SOAP | مغطى |
| وحدة الجراحة | 3 أقسام جراحية + Pre-Op Checklist Gate (§17.14) | مغطى |
| الشجرة العائلية (Pedigree) | علاقات العائلة والأوصياء + شاشة العائلة والنمو | مغطى جزئياً |
| لوحات المؤشرات الصحية | تقارير حسب الدور + KPIs تشغيلية ومالية | مغطى |
| كتابة التقارير الطبية | إصدار مستندات موقّعة + QR تحقق (verify.website.bh) | مغطى |
| اقتصاديات الصحة | فوترة VAT + مطالبات + تحصيل + ورديات | مغطى |

## الفجوات المتبقية

- Pedigree الرسومي (شجرة عائلية بصرية) — عندنا علاقات نصية فقط.
- سجلات Prenatal التفصيلية (زيارات الحمل المجدولة تلقائياً) — يمكن بناؤها فوق
  البرامج العلاجية (PathwayInstance) التي فُعِّلت حديثاً.

## ملاحظة

الترخيص؛ الاكتفاء بالتوثيق الوظيفي هنا يبعد أي التزام ترخيصي عن BMC.
